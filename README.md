## Descripción del proyecto
El sitio web consta de tres páginas interconectadas y adaptables a dispositivos móviles:
1. **Inicio (`index.html`):** Presentación general del proyecto y carrusel de imágenes interactivo.
2. **Galería (`galeria.html`):** Catálogo y exhibición de productos destacados organizados mediante Flexbox.
3. **Contacto (`info.html`):** Formulario de consulta con validación completa en JavaScript (sin alertas nativas y con mensajes en el DOM) y resumen dinámico de datos enviados.

---

## Instrucciones básicas de uso
1. **Navegación:** Utilice la barra de navegación superior presente en todas las páginas para desplazarse entre Inicio, Galería y Contacto.
2. **Carrusel de imágenes:** En la sección del carrusel, utilice los botones **"Anterior"** y **"Siguiente"** para visualizar las distintas creaciones. La navegación es de ciclo continuo (circular).
3. **Formulario de contacto:** 
   * Complete los campos solicitados (Nombre, Apellido, Teléfono, Email y Consulta).
   * Al hacer clic en **"Enviar"**, el sistema validará los datos mediante JavaScript en tiempo real. Si hay errores, se indicarán debajo de cada campo correspondiente.
   * Si todos los datos son válidos, se generará e insertará dinámicamente un resumen de la consulta en la parte inferior y el formulario se limpiará automáticamente para un nuevo ingreso.
   * Puede usar el botón **"Limpiar"** para borrar los campos en cualquier momento.

## Tecnologías utilizadas
* **HTML5:** Estructura semántica del contenido.
* **CSS3:** Estilos personalizados, diseño responsivo y uso de Flexbox (sin librerías ni frameworks externos).
* **JavaScript (Vanilla):** Lógica del carrusel, control del DOM y validación integral del formulario.
